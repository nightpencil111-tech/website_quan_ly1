# Phần 4 – Trợ lý: Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trợ lý gồm phần quy tắc (giao việc bằng câu tự nhiên, hỏi đáp dữ liệu, dàn ý văn bản) và phần AI qua Ollama (viết/sửa văn bản), bật/tắt được.

**Architecture:** Service thuần trong `src/services/assistant/`, router `src/routes/assistant.js`, view `views/assistant/`. Gọi Ollama bằng `fetch` của Node (stream NDJSON). Không thêm phụ thuộc.

**Tech Stack:** Node.js ≥ 22.13, express 4, ejs 3, node:sqlite; Ollama HTTP API (`/api/tags`, `/api/chat` stream).

**Spec:** `docs/superpowers/specs/2026-11-13-phan4-tro-ly-design.md`

## Global Constraints

- Không thêm phụ thuộc runtime. Toàn bộ chữ tiếng Việt, xưng "đồng chí". `requireLogin` trước `requireRole`. CSRF mọi POST (JSON dùng header `X-CSRF-Token`).
- Ngày theo `today()` giờ VN; hiển thị dd/mm/yyyy.
- Mã ý định hỏi đáp: `viec_qua_han, viec_cua, viec_den_han, viec_cua_toi, nghi_phep, chuyen_dang, het_han_phuc_vu, nien_han, dem_dang_doan, danh_sach_don_vi, qua_tai, tinh_hinh`.
- Mã dàn ý: `ke_hoach, bao_cao, bao_cao_tuan, bien_ban_sinh_hoat`. Tác vụ AI: `viet_noi_dung, sua_chinh_ta, van_phong_quan_doi, rut_gon, viet_lai`.
- Khóa settings AI: `ai_enabled` ('0'/'1', mặc định '0'), `ai_url` (mặc định `http://127.0.0.1:11434`), `ai_model` (mặc định `qwen2.5:3b`), `ai_timeout_s` (mặc định 180, 10–600), `ai_samples` (JSON, mỗi mục ≤ 4000 ký tự).
- Địa chỉ AI chỉ trong mạng nội bộ (spec §5); kiểm tra cả khi lưu và khi gọi (sau phân giải DNS).
- **Không bao giờ** đưa dữ liệu tư tưởng/hoàn cảnh vào câu trả lời hỏi đáp; **không bao giờ** gửi dữ liệu hồ sơ quân nhân tới AI.
- Nhật ký: `ai_run` (không lưu nội dung), `ai_settings`, — thêm nhãn tiếng Việt vào `AUDIT_ACTIONS` cho `ai_run`, `ai_settings`.
- Đọc `globals.md` trong workspace để biết API Phần 1–3.

### Task 4: Kết nối AI (Ollama)

- `getAiSettings(db)`, `saveAiSettings(db, data, actorId)` (validate; `assertPrivateUrl`; audit `ai_settings`).
- `assertPrivateUrl(url) → Promise<void>` — chỉ http/https; host theo spec §5; tên miền → `dns.lookup(all)` mọi IP phải nội bộ; AppError "Địa chỉ máy AI phải nằm trong mạng nội bộ".

- `runAi(db, user, {task, input, docType, extra}, onChunk, signal) → Promise<{chars_in, chars_out, ms}>` — từ chối nếu `ai_enabled` != '1' ("Trợ lý AI chưa được bật"); input rỗng/ > 8000 ký tự → AppError; một yêu cầu/người (Map userId → AbortController; giải phóng trong `finally`); gọi `POST {ai_url}/api/chat` `{model, stream:true, messages:[system, (mẫu văn), user]}` với `AbortSignal.any([signal, timeout])`; đọc NDJSON, gọi `onChunk(message.content)`; lỗi kết nối → AppError "Không kết nối được máy AI (<host>)"; hết giờ → "Máy AI phản hồi quá lâu"; audit `ai_run` (task, chars, ms).
